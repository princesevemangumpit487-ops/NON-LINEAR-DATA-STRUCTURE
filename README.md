# Assessment 3.3: Non-Linear Data Structure

Last name used: **MANGUMPIT** (the two M's are labeled M1 and M2)

| File | What it does |
|---|---|
| `binary_tree_program.py` | Builds the binary tree and prints BFS and DFS (preorder, inorder, postorder) |
| `graph_program.py` | Builds the graph and prints BFS and DFS |

Run with:

    python binary_tree_program.py
    python graph_program.py

Press Enter at the prompts to use the MANGUMPIT defaults.
